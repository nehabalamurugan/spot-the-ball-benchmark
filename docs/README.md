# Spot the Ball: Website

This folder contains the website files for the **Spot the Ball: A Benchmark for Visual Social Inference in Sports Scenes** project.

## Website Structure

- `index.html` - Main website page
- `static/` - CSS, JavaScript, images, and videos
- `README.md` - This file

## GitHub Pages Setup

To deploy this website on GitHub Pages:

1. Go to your repository **Settings**
2. Navigate to **Pages** section  
3. Under **Source**, select **Deploy from a branch**
4. Choose **main** branch
5. Set **Folder** to `/website`
6. Save settings

The website will be available at: `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME`
